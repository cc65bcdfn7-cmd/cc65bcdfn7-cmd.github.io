こえレシピ プライバシーポリシー

最終更新日: 2026年11月24日

こえレシピ（以下「このアプリ」）が、あなたの情報をどう扱うかを説明します。

1. 要点

  • 独自の会員登録はありません。投稿・いいね・通報は iCloud へのサインインが必要です。
  • 公開する投稿と、いいね・通報は Apple の CloudKit に送ります。声・献立・買い物の内容は送りません。
  • Siri やショートカットで使う時の声は、Apple の Siri が Apple の規約に従って扱います。このアプリは、その声や文字を受け取りません。アプリの中の声の操作（端末の中だけで処理）とは別です。
  • 設定の「保存を書き出す」で、端末に保存した内容をファイルにできます。共有するのは、あなたが共有を選んだ時だけです。開発者へは送りません。
  • 料理・献立などの機能は全部無料です。ホームと献立ルーレットの画面に広告（Google AdMob）が出ます。
  • 月額の自動更新サブスクリプション「広告なし」を購入すると、広告が出なくなります。
  • 料理中（声の操作・読み上げ・タイマー・確認の間）、レシピ・1週間の献立・買い物の画面には広告を出しません。
  • 広告を出す前に、iPhone の追跡の許可（App Tracking Transparency）の画面を1回出すことがあります（iPhone の設定で許可を求めないようにしている場合や、すでに答えている場合は出ません）。許可しなくても、すべての機能を使えます。あなたに合わせた広告になりうるのは、許可した場合だけです（同意の画面が出る地域では、その同意の内容にもよります）。

2. 端末に保存する情報

このアプリは、次の内容をあなたの iPhone の中に保存します。iPhone のバックアップ（iCloud やパソコンへのバックアップ）を使っている場合は、この保存もバックアップに含まれることがあります。

  • 1週間の献立（人数などの設定を含む）と、買い物のチェック
  • 保存した週（献立の組み合わせ）と、入れ替える前の週の控え
  • 料理の途中の状態（続きから再開するため）
  • お気に入りのレシピと、お気に入りのフォルダ（名前・色・絵・入れたレシピ）
  • レシピごとに自分で書いたメモ
  • 料理中の文字の大きさ（標準・大・特大）
  • レシピで最後に選んだ人数
  • 献立ルーレットで選ぶ種類（メイン・副菜・汁物）と、絞り込み（お気に入りだけ・20分以内）の入と切
  • 投稿の下書き・写真・ニックネームなど（くわしくは下の「投稿」）

投稿の下書きのうち、あなたが公開を選んだ内容は、下の「投稿」のとおり Apple の CloudKit に送ります。それ以外は開発者のサーバーには送りません。アプリを削除すると、端末の中の保存も消えます。

3. マイクと音声認識

料理中に「次」「もう一回」などの声の指示で手順を進めるために、マイクと音声認識の許可をお願いします。

  • 声は、あなたの iPhone の中だけで文字にします（端末内の音声認識）。声や文字を外部へ送りません。これはアプリの中の声の操作のことです。Siri は別で、下の「Siri・ショートカット（1.5）」をご覧ください。
  • 端末内の音声認識が使えない iPhone では、声の操作は使えません（外部の認識には切り替えません）。
  • 声の録音は保存しません。
  • 許可は、iPhone の「設定」からいつでも変えられます。許可しなくても、画面の操作でレシピは使えます。

4. 広告（Google AdMob）

  • 広告を出すために、Google の Google Mobile Ads SDK と、同意の管理のための User Messaging Platform（UMP）を使います。
  • 広告配信・計測・SDK改善のため、Googleが端末やアプリの識別子、IP由来の概略位置、広告操作、性能・診断情報を受け取る場合があります。Google での扱いは、Google のプライバシーポリシーと「Google のパートナーのサイトやアプリからの情報の利用」をご覧ください。
  • 追跡の許可（ATT）: 同意（UMP）の後、最初の広告を頼む前に、iPhone の許可の画面を1回出すことがあります（iPhone の設定やこれまでの答えによっては出ません）。料理中・「広告なし」の購読中には出しません。画面の文: 「あなたに合った広告の表示・効果測定のため、広告識別子を他社アプリ等の利用情報と関連付けます。許可しなくても全機能を使えます。」

- 許可した場合: 広告識別子（IDFA）を使い、あなたに合わせた広告を頼みます（同意の画面が出る地域では、その同意の内容の範囲で）。広告識別子は、Google が他社のアプリ・サイトの情報と関連付けて、広告の表示と効果の測定に使うことがあります。

- 許可しない・制限されている場合: あなたに合わせない広告（非パーソナライズ）だけを頼みます。広告識別子（IDFA）は使いません。

- あとから変えるには: iPhone の「設定」→「プライバシーとセキュリティ」→「トラッキング」でこのアプリを切り替えます。アプリに戻ると、次の広告から反映されます。

  • 広告の内容は全年齢向けに限ります。アプリが位置情報の取得を求めることはありません。広告の音は消しています。
  • 声・献立・買い物・お気に入りの中身は、広告に渡しません。
  • EU（27か国）では配信していません。英国・スイスなどでは、広告の前に同意の画面（UMP）が出ます。同意しない場合も、アプリの機能は使えます。同意は、設定の「広告の設定」から変えられます。
  • 「広告なし」を購読中の間は、広告を出さず、広告を求めることもしません。
  • 広告が始まった後に「広告なし」を購入した場合、広告の SDK はアプリを再起動するまで読み込まれたまま残ることがありますが、その間も広告を出さず、広告を求めることもしません。

5. アプリ内課金（「広告なし」）

  • 購入・更新・解約・返金は Apple が扱います。支払いの情報を、このアプリや開発者は受け取りません。
  • 購読しているかは、毎回 Apple（StoreKit）に問い合わせて決めます。購入の状態を開発者のサーバーへ送ることはありません。
  • 解約は iPhone の「設定」→ Apple ID →「サブスクリプション」からできます。

6. 解析と追跡

投稿・いいね・通報は上記の機能提供のために扱い、広告以外の利用状況の解析は行いません。広告の SDK（Google）が集める情報と、追跡の許可の扱いは、上の「4. 広告」のとおりです。追跡の許可をしない場合、広告識別子（IDFA）は使いません。

7. 子どもについて

投稿時にはニックネームを扱います。連絡先や個人情報を投稿に入れないでください。広告の SDK（Google）が受け取る情報は「4. 広告」のとおりです。広告は全年齢向けの内容に限ります。

投稿（1.2・1.5）

  • 公開したレシピ（料理名・材料・量・手順・種類・時間・人数・コツ）・写真（完成の写真と手順の写真）・ニックネーム、いいね・通報を Apple の CloudKit に保管します。コツは任意で、500字までです。CloudKit の利用者の記録 ID と作成日時に紐付きます。目的は投稿の公開、いいねの表示、不適切な内容への対応というアプリの機能です。投稿の内容を広告や追跡には使いません。
  • 投稿は運営の審査の後に公開されます。承認後、本文・コツ・写真・ニックネーム・投稿日時を一般に表示します。審査中・却下の内容（コツと、すべての写真を含む）も CloudKit の公開データベースに保存され、アプリの外から読めることがあります。通報は一般に公開せず、通報者と運営が扱います。運営は通報を確認し、禁止事項に当たる投稿・投稿者を非表示にできます。
  • 写真は PhotosPicker で選んだ物だけを受け取ります。1つの投稿に付けられるのは、完成の写真が4枚まで、手順の写真が10枚までです（手順の写真は、1つの手順に1枚）。公開前に、位置情報などの元のメタデータを除いて描き直し、完成の写真は JPEG 500KB以下、手順の写真は JPEG 200KB以下へ変換します。写真に写る内容や、本文・コツに自ら書いた位置・個人情報は除去できません。
  • 書いた中身（コツを含む）と写真の原本は、公開の成功・失敗後も端末に保存します。写真の並びと、公開から消すための待ち記録も端末に保存します。下書き・原本には iPhone のバックアップが適用されることがあります。ブロック・自分の通報の非表示・規約同意の印も端末に保存します。
  • 自分の投稿はアプリから公開を削除できます。削除すると、その投稿の写真（完成・手順）も公開から消します。通信できずに消せなかった時は、端末に待ち記録を残し、あとでやり直します。削除しても端末の原本は残ります。アプリを削除すると端末の原本も失われます。公開済みの投稿はアプリの削除だけでは消えないため、先に投稿を削除するかサポートへ依頼してください。公開した内容を他人が保存したコピーは運営では削除できません。
  • 本文・写真の通報と投稿者のブロックはレシピ画面から行えます。通報の未送信分は端末に残し、接続後に再送します。削除依頼・問い合わせはサポート窓口へ。運営は対応に不要となった通報記録を削除します。

運営の端末だけで、審査画面の初回利用時に通知の許可を求めます。審査待ちの通知には投稿の題だけを含め、写真・本文は含めません。

Siri・ショートカット（1.5）

  • Siri やショートカットから、「材料を読んで」「次の手順」「今日の献立」を使えます。どれも、iPhone のロックを解除してから動きます。
  • アプリが受け取るのは、どの指示が呼ばれたかだけです。Siri が聞き取った声や文字は、アプリは受け取らず、保存せず、送りません。
  • アプリは、返事の文（「今日の献立」では今日の料理名）を Siri に渡します。Siri がそれを読み上げ・表示します。
  • Siri に話した声は、Apple の Siri が Apple の規約に従って扱います。このアプリが端末の中だけで処理するわけではありません。くわしくは Apple のプライバシーに関する案内をご覧ください。
  • 「3. マイクと音声認識」の声の操作は、アプリの中の機能です。Siri とは別に動きます。

保存の書き出し（1.5）

  • 設定の「保存を書き出す」で、端末に保存した内容を JSON ファイルにできます。あなたが「ファイルを作る」を押した時だけ作ります。
  • 含むのは、お気に入り・フォルダ・メモ・料理の続き・献立・保存した週・ルーレットの設定・文字の大きさ・最後に選んだ人数、投稿のニックネームと自分の下書き（コツと、位置情報などのメタデータを除いた写真を含む）、ブロックと通報の件数などです。
  • アカウントの情報・CloudKit の識別子・購入と広告の情報・端末の識別子・他の人の投稿の内容は含みません。
  • ファイルは、アプリの一時の場所に作ります。この画面を閉じると消します。外へ出るのは、あなたが「共有する」を押し、iPhone の共有の画面で送り先を選んだ時だけです。選んだ送り先での扱いは、その送り先によります。
  • 書き出しの作成と共有で、開発者へ何かを送ることはありません。

買い物リストの共有と「家にある」（1.6）

  • 「家にある」の印は、この端末だけに保存します。
  • 買い物リストの共有は、あなたが共有のボタンを押し、iPhone の共有の画面で送り先を選んだ時だけ行います。送るのは、まだ買っていない材料（「家にある」の物を除く）の名前・量・売り場と、リストを作った日時だけです。開発者へは送りません。選んだ送り先（LINE など）での扱いは、その送り先によります。
