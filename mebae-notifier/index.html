Mebae Studio

ゲームやアプリの公開・アップデート・テスター募集の告知文を作るiPhoneアプリです。

サポートプライバシーEnglish

サポート

不具合やご意見は mebaegames@gmail.com へお知らせください。アプリのバージョン（設定の「このアプリについて」）、iOSのバージョン、問題が起きた操作を添えてください。パスワードや認証情報は送らないでください。

使い方

  1. 「作品」タブで作品を登録します（App Store・Google Play・その他の公開ページ）。
  2. 「投稿」タブの「新規作成」で、新規公開・アップデート・テスター募集の告知文を作ります。App Storeの作品は、公開を確認してから作成します。
  3. 「Xで投稿画面を開く」で、文章が入ったXの投稿画面を開きます。投稿の確定はXで自分で行います。

GitHubでの自動通知（任意）

ストアの定期チェックとメール通知は、別に用意したGitHub Actionsで動きます。アプリの「設定」で書き出した設定JSONを、GitHubの config/apps.json に反映してください。アプリだけではストアの監視やプッシュ通知は行いません。

プライバシーポリシー

作品の設定、作った告知文、登録したGitHubリポジトリのURLは、iPhoneのアプリ領域にだけ保存します。開発元のサーバーへの送信、アカウント登録、アクセス解析、広告、アプリをまたぐトラッキングはありません。アプリを削除すると保存した内容も消えます。

App Storeの公開を確認するときは、入力したアプリIDと国コードをAppleの公開検索（iTunes Lookup）に送ります。「Xで投稿画面を開く」を押すと、選んだ告知文がXに渡ります。GitHubのリンクを開くとGitHubのページが表示されます。設定JSONの書き出し先は、あなたが選んだ場所です。接続先でのデータの扱いには、各サービスのプライバシーポリシーが適用されます。

  • Appleのプライバシー
  • Xのプライバシー
  • GitHubのプライバシー

問い合わせに含まれる情報は、問い合わせへの対応にだけ使います。

Support

For bugs or feedback, email mebaegames@gmail.com. Please include the app version (Settings > About this app), your iOS version, and what you were doing. Never send passwords or credentials.

How to use

  1. Add your projects in the Projects tab (App Store, Google Play, or any other public page).
  2. Tap New draft in the Posts tab to create a release, update, or tester-recruitment post. App Store projects are checked for public availability first.
  3. Tap “Open the post screen in X” to open X with the text filled in. You always confirm the post yourself in X.

Automatic notifications with GitHub (optional)

Scheduled store checks and email alerts run in a separate GitHub Actions setup. Export the settings JSON from the app and apply it to config/apps.json on GitHub. The app alone does not monitor stores or send push notifications.

Privacy Policy

Your project settings, drafts, and the GitHub repository URL you enter are stored only on your iPhone. There is no developer server, no account, no analytics, no ads, and no cross-app tracking. Deleting the app deletes this data.

When you check a release on the App Store, the app ID and country code you entered are sent to Apple’s public lookup (iTunes Lookup). When you tap “Open the post screen in X”, the selected text is passed to X. Opening a GitHub link shows GitHub’s page. Exported settings files go wherever you choose. Each service’s own privacy policy applies to data it receives.

  • Apple Privacy
  • X Privacy
  • GitHub Privacy

Information in support emails is used only to respond to you.
